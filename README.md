# IA Music Generator Pro

## Uso no GitHub Actions
1. Actions → "Gerar Música Automática" → Run workflow
2. Escolha estilo/prompt/duração
3. Músicas em song_output/ numeradas

## Uso local (Termux)
```bash
pip install numpy scipy soundfile
python music_generator.py
```

## Estilos
epic, bossfight, dark, rock, ambient, electronic, jazz, classical, breakcore

## Modelo
xlarge (~50 milhões de parâmetros)
